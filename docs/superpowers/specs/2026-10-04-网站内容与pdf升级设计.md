# 网站内容与 PDF 升级设计

## 目标

将 life.apiferry.cc 从固定收录 649 条的旧版站点，升级为与原项目提交 91a4f53 一致的 654 条完整阅读站，并接入 397 页官方 PDF。

## 范围

- 更新 34 章、654 条建议及其来源、证据等级和性价比标记。
- 保留搜索、筛选、章节阅读、术语表、本地收藏、待做、完成状态和深色模式。
- 首页和全书页增加官方 PDF 的在线阅读与下载入口。
- 版本说明、页脚统计与风险提示同步至新版。
- 继续保持 GitHub Pages 纯静态部署，不引入后端、登录、支付或数据库。

## 数据流

1. 从原项目固定提交 91a4f53 读取 book/ 和 README.md。
2. 本地导入脚本生成 guide-full.json 与 glossary.json。
3. 数据校验器核对章节数、条目数、证据统计、性价比统计与风险标记。
4. React 站点仅读取生成后的静态 JSON，不在浏览器中请求外部 API。

## PDF 交互

- 主路径为 /how-to-live-better.pdf。
- “在线阅读”在新标签页打开 PDF。
- “下载 PDF”使用浏览器原生下载能力。
- 保留旧 PDF 路径，防止已经分享的旧链接立即失效。

## 验收

- 数据门禁通过：34 章、654 条、A/B/C 为 429/174/51，性价比为 111/298/245，争议 65 条、待核实 3 条。
- TypeScript 检查与 Vite 构建通过。
- 首页、全书页、建议详情页、版本说明页和 PDF 入口在桌面端、手机端可用。
- 本地服务器无 404、JavaScript 错误或缺失资源。
